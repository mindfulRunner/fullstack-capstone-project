This is a gift sharing website where people can find their needed stuff for free and be inspired to share their stuff too.

This is a complete full stack project covers both front end and back end.

Front end and back end uses MERN stack.

As a distributed system, front end, back end, mongoDB were built into Docker images and deployed onto separate Kubernetes pods in IBM Cloud.

Techs:

	Front end:
	
		JavaScript, React, React Hooks, HTTP fetch, navigation, session storage, async / await
	
	Back end:
	
		JavaScript, Node.js, Express.js, CORS, Router, REST API, JWT, MongoDB, async / await
	
	Containerization:
	
		Docker, Kubernetes, IBM Cloud
